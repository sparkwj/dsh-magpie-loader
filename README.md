# dsh-magpie-loader

English | [简体中文](README.zh-CN.md)

A DeepSeek Harness (DSH) plugin that runs magpie with DSH: it starts when DSH starts and stops when DSH exits.

## Installation

1. Install and open magpie, then go to **Settings** > **About** and click **Add magpie command line to environment**.
2. In DSH, open **Plugins** > **Add plugin** and install `dsh-magpie-loader`.
